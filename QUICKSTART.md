## Быстрая установка

```bash
# 1. Установите зависимости
npm install

# 2. Настройте переменные окружения
# Откройте .env.local и заполните значения
```

## Минимальная конфигурация для запуска

1. **Supabase** (обязательно):
   - Создайте проект на https://supabase.com
   - Выполните SQL из `supabase_schema.sql`
   - Скопируйте URL и anon key в `.env.local`

2. **Запустите проект**:
```bash
npm run dev
```

3. **Откройте в браузере**:
```
http://localhost:3000
```

## Что требует настройки для полного функционала

### Phone Auth (для входа)
- Настройте SMS провайдер в Supabase
- Или используйте email auth как альтернативу

### YooKassa (для оплаты)
- Получите Shop ID и Secret Key
- Добавьте в `.env.local`
- Настройте webhook

### Yandex Maps (для карты)
- Получите API ключ
- Добавьте в `.env.local`
- Измените координаты в `components/MapView.tsx`
